## v1.14.2：仓库迁移到 ps5-manage

v1.4.0 及以后的版本都可以在「设置 → 服务更新」一键升级。

### 改动

- **仓库地址改为 [`wujiezero/ps5-manage`](https://github.com/wujiezero/ps5-manage)。** 一键安装命令、网页更新检查、发布链接、systemd 文档和升级文档都已改用新地址。
- **旧版本仍可升级。** GitHub 会把旧仓库地址重定向到新仓库；升级到 v1.14.2 后不再依赖这个重定向。

### 升级

- 网页一键升级，不需要修改配置。
- 本版本只有仓库地址和文档更新，没有功能和配置变化。
