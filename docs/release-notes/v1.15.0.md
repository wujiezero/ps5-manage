# v1.15.0

## 新增与改进

- **全面更名为 `ps5-manage`（平滑升级兼容）**
  - 服务目录、配置目录、数据目录、仓库目录、systemd 单元名称（`ps5-manage` / `ps5-manage-host` / `ps5-manage-repo`）、安装包名称、备份文件名与界面文案全部统一更新为 `ps5-manage`。
  - 兼容升级：Release 同时提供 `ps5-manage-1.15.0.tar.gz` 与兼容别名 `ps5-jb-server-1.15.0.tar.gz`，老版本（`v1.4.0–v1.14.3`）可直接通过管理页面一键在线更新；运行 `sudo ./install.sh` 升级时也会自动迁移原 `/etc/ps5-jb-server`、`/var/lib/ps5-jb-server`、`/srv/ps5-jb-server` 与 systemd 单元配置。
- **网络活动页支持单行一键放行与域名规整合并**
  - 实时活动与历史记录列表新增「操作」列，未放行的目标可直接在行尾点击「放行」，无需逐行勾选弹窗确认（优先按已解析域名放行，已放行/内置域名/本机服务显示对应状态）。
  - 后端放行时自动规整域名大小写、末尾点号与 IDNA，清理已被通配符覆盖的冗余规则，并将同级兄弟子域智能合并为 `*.parent`（保留根域名独立匹配，并保护公共多级后缀与多租户 CDN 根域），同时对重叠或相邻的 IPv4 CIDR 做无损合并。
- **PS5 主机持久化记忆与断线重连状态自动识别**
  - 即使主机处于断网、关机或休眠，扫描与重载插件后不再从列表消失；配对、唤醒、待机、添加或设置为文件主机时都会自动持久化记录。
  - 重连和轮询时批量发起 DDP + TCP 探测，清晰显示「已唤醒 · 在线」「已唤醒 · 未运行载荷」「待机中」「已离线」状态，并支持在离线卡片中点击「移除记忆」手动清理；手动输入 IP 改为即时添加与探测。
- **概览页：主机开放 ELF 端口扫描与服务卡片**
  - 自动探测 PS5 上已启动 ELF 所监听的端口，对照 GitHub 开源资料（Payload Manager、Web File Manager、websrv、etaHEN、ps5upload、ftpsrv、zftpd、elfldr、klogsrv、ps5debug 等）识别服务名称、说明与仓库来源。
  - Web 类服务卡片点击可直接在新窗口打开页面；FTP / ELF / 调试端口点击可一键复制连接地址。
- **概览页：PS5 硬件、存储与当前游戏状态面板**
  - 结合 `ps5upload` 引擎与主机存储/标题库/DDP 数据，在概览页新增四张实时状态卡片：
    - **处理器**：CPU 频率与逻辑核心、CPU/SoC 温度、整机 SoC 功耗、CPU 负载与风扇转速、负载进度条。
    - **内存**：已用/总量、游戏显存池（Direct Memory）、内存使用率进度条及 Swap / 常驻内存。
    - **存储**：内置存储、外置 USB、扩展 M.2 分区占用率与容量条（含阈值颜色提示）。
    - **当前游戏**：运行帧率（FPS）、中文/英文游戏名与 Title ID、开发商/类型、本地缓存封面图及运行状态标记。
