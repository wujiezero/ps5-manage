## v1.14.3：插件和组件跟进上游最新版

v1.4.0 及以后的版本都可以在「设置 → 服务更新」一键升级。

### 改进

- **常用插件都换成了上游最新版。** ELF 加载器、PS4 光盘挂载、网页文件管理器和 PS5 上传工具都有更新，新装就直接拿到新版。
- **用户手册入口支持更多主机版本。** 内置的用户手册宿主升级后，覆盖的主机系统版本更广，更新前打不开用户手册的主机可以再试一次。
- **唤醒 / 待机组件同步更新。** 可选的电源控制引擎与主机上的上传工具版本对齐，减少两边版本不一致带来的问题。

### 升级

- 网页一键升级，不需要修改配置。
- 已经装过插件的主机不会被动替换：插件在「设置 → 插件更新」里逐个升级，也可以等下次重装时自动换成新版。
- 用过唤醒 / 待机的主机，升级后重跑一次安装脚本并保留 `--with-power-engine` 参数即可换上新的电源控制引擎。
