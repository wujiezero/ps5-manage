# v1.15.1

## 修复与改进

- **网络活动页不再允许放行单标签非标准域名（如 `file`）**
  - 当 PS5 发起单标签主机名解析（例如 `file`）时，此类名称既无法在公网解析、也不属于标准域名格式。页面现在会自动隐藏其勾选框与「放行」按钮，并在操作列和统计列表中标为「非标准域名」，避免点击放行时触发「域名不合法」报错。
- **降低概览探测频率，避免后台传输期间占用主机连接**
  - 概览页「主机开放服务」由原先每 25 秒周期性扫描改为**进入概览或切换主机时扫描一次**（后续仅在手动点击「扫描端口」/「刷新」时重扫）。
  - 检测到正在进行上传或 NAS/PKG 传输任务时，自动跳过概览页的周期性端口扫描与硬件遥测轮询（前后端均生效），避免干扰主机的流式传输会话。
